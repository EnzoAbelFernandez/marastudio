## 2024-05-15 - Screen Reader Continuity for Animated Split Text\n**Learning:** When text is split into multiple `<span>` elements for fine-grained character or word animations (e.g., using a custom `SplitText` component or splitting a paragraph by words), screen readers announce each span disjointedly, destroying the natural reading flow. The fix is consistently wrapping the full text in a `.sr-only` visually hidden span while applying `aria-hidden="true"` to all individual animated pieces.\n**Action:** Always verify custom text animation components with this `.sr-only` wrapper and `aria-hidden` combination to ensure accessibility isn’t sacrificed for visual flair.
